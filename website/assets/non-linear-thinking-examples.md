# Examples of non-linear thinking

This is a working catalogue for the YC Match profile and the Geometry Finance Lab site. Each entry should preserve the event, identify the structural move, and distinguish observation from interpretation.

## 1. Comfort through structure

**Participants:** Nik and Cody, with the result to be shared with Argus.

**Event:** The site menus had become difficult to read when too many choices appeared at the same level.

**Structural move:** Instead of adding more explanations, removing useful material, or enlarging the interface, we reorganized the existing lines into deeper groups with no more than four choices at each level.

**Result:** The same information became dramatically more readable and comfortable. A problem that first looked visual was improved by changing the information structure.

**Why it matters:** This is an example of non-linear thinking in practice: preserve the information, change the frame, and test the result in lived use.

**Status:** Observed and confirmed by Nik after testing the revised menus.
